Scenario: Ransomware group workflow

Composite 16-day attack with defender detection points.

Day 1–7 Recon: Scan external IPs, scrape LinkedIn, LLM-drafted spear-phish.

Day 8 Initial access: Fake M365 login (Evilginx), residential proxy login.

Day 9–14 Lateral movement: BloodHound on Windows, path to Domain Admin, LLM summarizes SharePoint for high-value shares.

Day 15 Exfil: Compress data, upload to S3 overnight, persistence via scheduled task.

Day 16 Impact: Ransomware via GPO/PsExec, AI chatbot for negotiation.

Detection: Impossible-travel login, unusual MFA, LDAP enumeration, mass file access, outbound data spike, shadow copy deletion.

Scenario: AI application target

Step 1: Map customer RAG chatbot API and vector DB.

Step 2: Prompt injection extracts system prompt with API keys.

Step 3: Tool abuse — agent queries CRM and emails export to attacker.

Step 4: RAG poisoning via support ticket attachment indexed into knowledge base.

Step 5: Poisoned content persists; data sold on dark web.

Detection: Unusual agent tool volume, emails to unknown domains from bot account, spike in new document retrieval.

Ethical lab setup (mirror attackers legally)

  • Primary OS: Kali or Parrot in VirtualBox — isolated network
  • Target lab: TryHackMe, HackTheBox, DVWA
  • AI lab: AIRT Docker labs, local Ollama
  • Windows lab: GOAD Active Directory homelab
  • Monitoring: Wazuh or Elastic SIEM to see attacker artifacts in logs
